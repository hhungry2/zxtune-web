ZXTune Web NEW • WASM

ブラウザだけで完結 • インストール不要 • PWA対応 • 開いた曲はオフラインでも再生

AudioWorklet合成インストール不要WASMコア

最も手軽なZXTune。 C++コアをEmscriptenでWebAssembly化し、AudioWorkletで途切れない合成を実現。サーバにファイルを送らず、ブラウザ内で完結してデコードするためプライベートかつ高速です。

使い方

  1. player.html を開く
  2. .pt3 / .spc / .nsf / .sid / .vgm / .zip / .trd をドラッグ＆ドロップ
  3. プレイリストから選んで ▶ — スペクトラムを見ながら再生！

Webならではの機能

  • URL読み込み・共有 — GitHub や ModArchive など、ブラウザからの読み込み (CORS) を許可するサイトの曲を URL で開けます。player.html?url=… で共有も (zxtunes.com / HVSC は CORS 非対応のため不可)
  • チャンネルミュート — A/B/Cをクリックでミュート (AY 系のチャンネル割り当て)、作曲技法の学習に
  • ビジュアライザ切替 — スペクトラム ↔ オシロスコープ（キャンバスクリック）
  • PWA — ホーム画面に追加でネイティブアプリのように動作
  • メディアキー — キーボードのメディアキーやロック画面から再生 / 一時停止 / 曲送り
  • XSPF — zxtune-qt と同じ形式のプレイリストを保存・読み込み

技術スタック

emscripten + AudioWorklet + WebAssembly + Canvas 2D。メインスレッドをブロックせず、出力デバイスのサンプリング周波数で合成 (補間は高品質 / 低品質 / なし)。

ZXTune Qt DESKTOP • Qt 5

Windows / macOS / Linux • いちばん多機能なプレイヤー

Qt 5UIWAV・MP3・OGG・FLACに変換XSPF・AYLプレイリスト

パワーユーザー向けのフラッグシップ。 プレイリストの管理と検索、曲ごとのプロパティ編集、音声ファイルへの変換、音源ごとの細かな設定までを一つのウィンドウで。

主な機能

  • プレイリスト — 検索 (正規表現も可) / 並べ替え / 重複の削除 / 統計 / XSPF 保存 (絶対・相対パス、曲データ埋め込み) / XSPF・AYL 読み込み
  • プロパティ — 曲ごとにタイトル・作者・コメントや、チップの種類・クロック・補間・レイアウトを設定
  • 変換 — 選んだ曲を WAV / MP3 / OGG / FLAC に一括変換 (マルチスレッド可)
  • 設定 — AY、SAA、SID、Z80、ミキサー、出力デバイス、形式ごとのオプション

インストール

公式サイト (zxtune.ru → zxtune.bitbucket.io) で Windows (x86_64 / ARM64)、macOS (Intel / Apple Silicon)、Linux (tar.gz / deb / rpm) 版が配布されています。ソースからは、Linux でシステムの boost と Qt を使うなら make system.zlib=1 -C apps/zxtune-qt でビルドします (BUILD.md)。

zxtune123 CLI • Headless

コンソール / スクリプト / サーバ • 軽量 • バッチ変換

--analyzerスペクトラム--convert形式変換--benchmark速度計測

端末で完結するミニマリスト。 GUI不要で再生・情報表示・変換・ベンチマーク。サーバでの自動変換や大量ファイルのバッチ処理に最適。

使用例

$ zxtune123 --help
$ zxtune123 track.pt3 # 再生 (← / → でシーク)
$ zxtune123 --analyzer track.pt3 # スペクトラムを表示して再生
$ zxtune123 --wav filename=[Author]-[Title].wav *.pt3 # WAV に書き出し
$ zxtune123 --convert mode=psg,filename=[Title].psg track.pt3 # PSG に変換
$ zxtune123 --list-plugins # 対応形式の一覧

特徴

  • 書き出し — --wav などの出力先にファイル名のひな形 ([Author]、[Title] など) を指定
  • 形式変換 — --convert で raw / PSG / ZX50 / TXT / AY ダンプ / FYM に変換
  • 一覧化 — --index で曲の情報を CSV に書き出し
  • ベンチマーク — --benchmark で描画の速さを計測
  • 設定 — --core-options などの指定を設定ファイル (--config) にまとめられます
