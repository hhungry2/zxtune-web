ZXTune Web NEW • WASM

ブラウザだけで完結 • インストール不要 • PWA対応 • オフライン再生

48kHz合成0秒起動WASMコア

最も手軽なZXTune。 C++コアをEmscriptenでWebAssembly化し、AudioWorkletで途切れない合成を実現。サーバにファイルを送らず、ブラウザ内で完結してデコードするためプライベートかつ高速です。

使い方

  1. player.html を開く
  2. .pt3 / .spc / .nsf / .sid / .vgm / .zip / .trd をドラッグ＆ドロップ
  3. プレイリストから選んで ▶ — スペクトラムを見ながら再生！

Webならではの機能

  • URL共有 — zxtunes.comやHVSCへの直リンクで即再生（対応予定）
  • チャンネルミュート — A/B/Cをクリックでソロ/ミュート、作曲技法の学習に
  • ビジュアライザ切替 — スペクトラム ↔ オシロスコープ（キャンバスクリック）
  • PWA — ホーム画面に追加でネイティブアプリのように動作

技術スタック

emscripten + AudioWorklet + WebAssembly + Canvas 2D。メインスレッドをブロックせず、48kHz / 32bit float / cubic補間で合成。

クイックスタート

$ open player.html
# drag & drop demo.pt3

ZXTune QT DESKTOP • Qt5/6

Windows / Linux / macOS • 最も高機能 • プラグイン拡張

Qtフレームワーク変換対応OGサポート

パワーユーザー向けのフラッグシップ。 プレイリストの高度な管理、検索、タグ編集、オーディオ変換、コンポーネント設定までを一つのウィンドウで。

主な機能

  • プレイリスト — 検索 / フィルタ / ソート / XSPF保存 / AYLインポート
  • 変換 — 一括でWAV/MP3/OGGへエクスポート（サンプリング周波数・補間選択可）
  • オーディオ設定 — AYMチューニング(ABC/ACB…)、補間、ステレオセパレーション、ローパス
  • プラグイン — 新フォーマットや出力デバイスを追加可能

インストール

https://zxtune.ru からバイナリを取得、または make -C apps/zxtune-qt でビルド。依存はQt5/6とzlibのみ。

zxtune123 CLI • Headless

コンソール / スクリプト / サーバ • 軽量 • バッチ変換

makeビルドpipe対応bench内蔵

端末で完結するミニマリスト。 GUI不要で再生・情報表示・変換・ベンチマーク。サーバでの自動変換や大量ファイルのバッチ処理に最適。

使用例

$ zxtune123 --help
$ zxtune123 track.pt3 # 再生
$ zxtune123 --info track.spc # メタ情報
$ zxtune123 --convert --mp3 *.pt3 # 一括MP3
$ make -C apps/zxtune123 system.zlib=1 # ビルド

特徴

  • 依存最小 — C++とzlibのみ
  • stdoutパイプ / スクリプト連携
  • ベンチマークモードで最適な補間を探索
